# Zylcut

**Zylcut** is a local AI video editor for macOS, Windows and Linux.

Your coding agent (Claude Code, Codex, Cursor, OpenCode, Gemini CLI or any MCP client) cuts dead air, captions every word and checks the edit. You review it and fine-tune it on a real timeline. Transcription, editing and export run on your computer, so your footage never leaves it.
